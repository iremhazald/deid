# First-name lexicon provenance

`first_names.py` holds a small, locally maintained set of commonly attested
Turkish given names.

- Source: editorial compilation of public-domain factual given names
- License: no third-party dictionary dump; names themselves are not copyrighted
- Runtime: loaded from the local package only; no network lookup
- Role: optional evidence (`first_name_lexicon`). Never a PERSON detector.
